KurdNet

A Deep Learning-Based System for Recognition of Kurdish Handwritten Characters and Digits

Open-source • Research • Educational use
Demo GitHub

1. Overview

KurdNet is a web-based demo for real-time recognition of Kurdish handwritten characters and digits. Users draw a single character or digit on the canvas, and a convolutional neural network (CNN) predicts the most likely class. The system is intended for academic, research, and educational use, especially in handwriting learning tools and classroom environments.

2. How to Use the Demo

  1. Open the Demo page (index.html) in a modern web browser.
  2. Use your mouse, trackpad, or touchscreen to draw a single Kurdish letter or digit inside the black canvas area.
  3. If you make a mistake, click Clear to reset the canvas.
  4. When you are satisfied with the drawing, click Predict.
  5. The model output and confidence scores are displayed in the results panel next to the canvas.

The app is responsive and can be used on desktops, laptops, tablets, and phones. For best handwriting quality, a touchscreen or pen-enabled device is recommended.

3. Supported Characters and Digits

The current model is trained on:

  • 35 Sorani Kurdish letters written in the modified Arabic script.
  • 10 numerical digits (Eastern Arabic digits ۰–۹ or mapped equivalents).

Each input should contain one clearly written character or digit. Multi-character words or connected text are not supported in this demo version.

4. How KurdNet Works (Short Technical Description)

When the user clicks Predict, the drawing is captured from the HTML5 canvas and converted to a grayscale image. The image is resized and normalized to match the input format of the trained CNN. The model, implemented with TensorFlow.js in the browser or via a backend API (depending on configuration), computes class probabilities for all characters and digits, and the top prediction is shown to the user along with a confidence score or chart.

5. Example Use Cases

  • Handwriting practice for children: integrate KurdNet into learning apps so students can practice letters and receive immediate automated feedback.
  • Classroom demonstrations: teachers can show how machine learning recognizes handwritten Kurdish script in real time.
  • Prototype data-entry tools: explore handwriting input instead of keyboards for simple forms or labels.
  • Research experiments: use the demo to collect error cases or test new model variants.

6. Current Limitations

  • Designed for single-symbol input (one letter or digit at a time).
  • Performance may decrease for very small, very large, or extremely stylized handwriting.
  • Background noise, poor contrast, or very fast strokes can affect recognition quality.
  • The system is a research/educational prototype and is not intended for security-critical or production-grade OCR tasks without further validation.

7. Data and Privacy

The demo processes drawings in-memory for prediction. No personal data is requested, and no user drawings are stored or logged by default. If data collection is enabled in a research setup, users should be informed and local ethics or institutional guidelines must be followed.

8. For Developers

The source code is available on GitHub and can be cloned and run locally. A typical setup includes:

  1. Clone the repository from GitHub.
  2. Serve the project with a simple HTTP server (e.g. python -m http.server).
  3. Open index.html in a browser to access the demo.
  4. Modify the JavaScript or model files to experiment with new architectures or datasets.

Detailed installation and development instructions are provided in the project README.
